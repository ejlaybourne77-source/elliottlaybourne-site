Add the VIX:VIX3M regime indicator to TradingView

The volatility term-structure ratio the desks watch to see trouble coming. It installs manually in about two minutes. Copy the code below into TradingView's Pine Editor and add it to your chart.

What you're installing

This plots the ratio of VIX (30-day implied volatility) to VIX3M (3-month). When near-term fear spikes above longer-term, the ratio climbs, and history shows the concurrent stress in the market rises with it. The indicator colours that reading into five regimes:

Calm< 0.85 · baseline vol
Normal0.85 to 0.95
Stressed0.95 to 1.00 · ~2× vol
Severe1.00 to 1.05 · ~3× vol
Extreme> 1.05 · ~4× vol

The dashed line at 0.95 is the one to watch: that's where near-term stress historically begins to bite. This is a context and risk-regime tool, not a buy/sell signal.

Install in six steps

  1. Open TradingView and load any chart: SPX, ES or SPY make good context.
  2. At the bottom of the screen, click the Pine Editor tab to open the editor panel.
  3. Select everything already in the editor (Ctrl/Cmd + A) and delete it.
  4. Copy the code below and paste it into the empty editor (Ctrl/Cmd + V).
  5. Click Save (top-right of the editor), name it VIX:VIX3M Regime.
  6. Click Add to chart. The indicator appears in its own pane below price.
The indicator code 
//@version=6
indicator("VIX:VIX3M regime (premium)", shorttitle="VIX:VIX3M", overlay=false)

// ---- data ----
vixSym   = input.symbol("CBOE:VIX",   "VIX (30d)")
vix3mSym = input.symbol("CBOE:VIX3M", "VIX3M (3m)")
float vix   = request.security(vixSym,   timeframe.period, close)
float vix3m = request.security(vix3mSym, timeframe.period, close)
float ratio = na(vix) or na(vix3m) or vix3m == 0 ? na : vix / vix3m

// ---- thresholds ----
g     = "Bands"
bLow  = input.float(0.85, "Calm / Normal",             step=0.01, group=g)
bMid  = input.float(0.95, "Normal / Stressed (DIVIDER)",step=0.01, group=g)
bBase = input.float(1.00, "Stressed / Severe",          step=0.01, group=g)
bExt  = input.float(1.05, "Severe / Extreme",          step=0.01, group=g)
bFloor= input.float(0.80, "Floor anchor",              step=0.01, group=g)
bCeil = input.float(1.25, "Ceiling anchor",            step=0.01, group=g)

// ---- palette ----
gc        = "Colours"
cCalm     = input.color(#17C25F, "Calm  (green)",   group=gc)
cNormal   = input.color(#9AD52A, "Normal (lime)",   group=gc)
cStressed = input.color(#FFB300, "Stressed (amber)",group=gc)
cSevere   = input.color(#FB6A00, "Severe (orange)", group=gc)
cExtreme  = input.color(#F5333C, "Extreme (red)",   group=gc)
bandTp    = input.int(82, "Band fade (higher = fainter)", minval=50, maxval=95, group=gc)
sepCol    = input.color(#C9D2DE, "Zone separators (off-grey)", group=gc)
divCol    = input.color(#EAF0F8, "0.95 divider",    group=gc)

// ---- display ----
gd       = "Display"
lineW    = input.int(2, "Line thickness", minval=1, maxval=5, group=gd)
outlineW = input.int(3, "Black outline (extra px)", minval=0, maxval=6, group=gd)
showKey  = input.bool(true, "Show key bar", group=gd)
keyLoc   = input.string("Top", "Key location", options=["Top","Bottom"], group=gd)
showBrand= input.bool(true, "Show brand mark", group=gd)
brandTxt = input.string("ELLIOTT LAYBOURNE", "Brand text", group=gd)

// ---- current regime ----
int lvl = na(ratio) ? -1 : ratio < bLow ? 0 : ratio < bMid ? 1 : ratio < bBase ? 2 : ratio < bExt ? 3 : 4

// ---- band boundaries + off-grey separators ----
hF = hline(bFloor, "", color=color.new(color.gray, 100))
h1 = hline(bLow,   "", color=color.new(sepCol, 30), linestyle=hline.style_dashed)
h2 = hline(bMid,   "0.95 · CALM | STRESSED", color=color.new(divCol, 15), linestyle=hline.style_dashed, linewidth=1)
h3 = hline(bBase,  "", color=color.new(sepCol, 30), linestyle=hline.style_dashed)
h4 = hline(bExt,   "", color=color.new(sepCol, 30), linestyle=hline.style_dashed)
hC = hline(bCeil,  "", color=color.new(color.gray, 100))

// ---- faded band fills ----
fill(hF, h1, color=color.new(cCalm,     bandTp))
fill(h1, h2, color=color.new(cNormal,   bandTp))
fill(h2, h3, color=color.new(cStressed, bandTp))
fill(h3, h4, color=color.new(cSevere,   bandTp))
fill(h4, hC, color=color.new(cExtreme,  bandTp))

// ---- white line with medium black outline ----
plot(ratio, "outline",   color=color.new(#000000, 0), linewidth=lineW + outlineW)
plot(ratio, "VIX:VIX3M", color=color.new(#FFFFFF, 0), linewidth=lineW)

// ---- key bar: swatch + name + range; active = solid pill ----
f_num(x) => str.tostring(x, "#.##")
zName = array.from("CALM", "NORMAL", "STRESSED", "SEVERE", "EXTREME")
zCol  = array.from(cCalm, cNormal, cStressed, cSevere, cExtreme)
zLo   = array.from(0.0,  bLow, bMid,  bBase, 0.0)
zHi   = array.from(bLow, bMid, bBase, bExt,  0.0)
kPos  = keyLoc == "Top" ? position.top_center : position.bottom_center
var table k = table.new(kPos, 10, 1, frame_width=0, border_width=0)
if barstate.islast and showKey
    for i = 0 to 4
        bool  on  = lvl == i
        color col = array.get(zCol, i)
        string rng = i == 0 ? "<" + f_num(bLow) : i == 4 ? ">" + f_num(bExt) : f_num(array.get(zLo, i)) + "-" + f_num(array.get(zHi, i))
        table.cell(k, i*2, 0, "  ", bgcolor=col)
        string t = " " + array.get(zName, i) + " " + rng + (on ? "  " + str.tostring(ratio, "#.###") + " ◀" : "") + " "
        table.cell(k, i*2+1, 0, t, bgcolor=on ? col : color.new(#0B1220, 0), text_color=on ? color.new(#08101E, 0) : color.new(color.white, 15), text_size=size.small, text_halign=text.align_left)

// ---- brand mark ----
var table b = table.new(position.bottom_left, 1, 1)
if barstate.islast and showBrand
    table.cell(b, 0, 0, brandTxt, text_color=color.new(color.white, 55), text_size=size.small)

// ---- bonus alerts (fire on regime flips; usable on paid TradingView plans) ----
alertcondition(ta.crossover(ratio,  bMid),  title="Entered STRESSED (>0.95)", message="VIX:VIX3M crossed above 0.95, stress regime begins")
alertcondition(ta.crossover(ratio,  bBase), title="Entered SEVERE (>1.00)",   message="VIX:VIX3M crossed above 1.00, severe stress / backwardation")
alertcondition(ta.crossover(ratio,  bExt),  title="Entered EXTREME (>1.05)",  message="VIX:VIX3M crossed above 1.05, extreme stress")
alertcondition(ta.crossunder(ratio, bMid),  title="Back to CALM (<0.95)",     message="VIX:VIX3M crossed below 0.95, stress easing")

Reading it once it's on your chart

The white line is the live ratio. The coloured bands behind it are the regimes; the key along the top highlights the one you're in right now, with the current value. When the line pushes up through the 0.95 divider, near-term volatility is running hot relative to the term, and the market is starting to price trouble. Above 1.00 is genuine stress; above 1.05 is rare, crisis-grade territory.

The script reads CBOE:VIX and CBOE:VIX3M. Both are available on a free TradingView plan for daily data. If a symbol doesn't resolve on your account, swap it for TVC:VIX / INDEX:VIX3M in the indicator's settings.
